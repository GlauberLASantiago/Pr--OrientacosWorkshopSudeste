# 📘 Pré-Orientações para os Tutores - Workshop Regional Sudeste

O **Pré-Orientações para os Tutores - Workshop Regional Sudeste** é uma aplicação web desenvolvida para apresentar, de forma clara e organizada, informações iniciais sobre a participação de tutores em um workshop regional do projeto Posedu Digital. A página reúne informes gerais, critérios de participação e detalhes da programação do evento em uma interface simples, responsiva e visualmente agradável.

## ✨ Funcionalidades

- Apresentação de orientações iniciais para tutores
- Organização do conteúdo em seções temáticas
- Navegação fixa no topo da página
- Rolagem suave entre seções
- Animações de entrada ao percorrer a página
- Layout responsivo para diferentes dispositivos
- Destaque visual para informações importantes
- Rodapé com observações e link complementar

## 📚 Conteúdo abordado

A página reúne informações sobre:

- contexto e objetivo do encontro presencial;
- data, horário e local do workshop;
- critérios de participação de tutores e cursistas;
- responsabilidades financeiras de deslocamento e hospedagem;
- estrutura da programação do evento;
- organização das atividades da manhã e da tarde.

## 🛠️ Tecnologias Utilizadas

- **HTML5**
- **CSS3**
- **JavaScript**
- **Tailwind CSS**

## 🎯 Objetivo do Projeto

O projeto foi criado para transformar um comunicado institucional em uma página digital mais acessível e organizada, facilitando a leitura e a consulta das informações pelos tutores. A proposta é apoiar o alinhamento prévio dos participantes antes do workshop regional.

## ▶️ Como usar

1. Abra o arquivo HTML em um navegador moderno.
2. Utilize o menu superior para navegar pelas seções.
3. Leia os informes sobre participação e programação.
4. Consulte o rodapé para observações finais e recursos adicionais.

## 🧩 Estrutura da Página

A interface está organizada em quatro partes principais:

- **Início**
- **Participação**
- **Programação**
- **Rodapé**

Cada seção apresenta informações específicas para orientar os tutores sobre o evento.

## 🎨 Interface

O projeto utiliza uma identidade visual com cores institucionais fortes, combinando:

- cabeçalho fixo;
- blocos de conteúdo destacados;
- cartões interativos com efeito hover;
- tipografia legível;
- contraste visual entre seções.

## 📱 Responsividade

A página foi projetada para funcionar bem em:

- computadores
- tablets
- celulares

## 📁 Estrutura do Projeto

O projeto está concentrado em um único arquivo HTML contendo:

- **HTML**: estrutura do conteúdo
- **CSS**: identidade visual, animações e responsividade
- **JavaScript**: animações de entrada com observer de rolagem

## ✅ Possíveis usos

Este projeto pode ser utilizado como:

- comunicado digital para eventos;
- página de orientação prévia para participantes;
- material de apoio institucional;
- modelo para páginas informativas de workshops e encontros.
